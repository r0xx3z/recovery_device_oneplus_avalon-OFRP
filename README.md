# Device specifications 

| Device                  | OnePlus Nord 4                                  |
| ----------------------- | :---------------------------------------------------------- |
| SoC     		  | Qualcomm Snapdragon 7+ Gen 3 (SM7675)                    |
| CPU     		  | Octa-core (1× 2.8 GHz Cortex-X4, 4× 2.6 GHz Cortex-A720, 3× 1.9 GHz Cortex-A520) |
| OS Version  | OxygenOS 14.1 (Android 14) to Android 18 (ColorOS 18) |
| GPU     		  | Qualcomm Adreno 732                  |
| Memory      |  8 GB / 12 GB / 16 GB LPDDR5X                  |
| Storage     | 128 GB UFS 3.1 / 256 GB UFS 4.0 / 512 GB UFS 4.0               |
| Battery 		  | 5500 mAh, dual cell, Li-ion |
